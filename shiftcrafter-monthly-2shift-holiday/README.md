# ShiftCrafter Monthly (2-Shift/Holiday)

ShiftCrafter Monthly 2-Shift Holiday は、**2交代制（日勤・夜勤）** のシフト表を自動作成するブラウザベースのツールです。
特に**「休日数の厳密な管理」** と **「連休の確保」** に重点を置いています。

## 主な機能

*   **2交代制シフト作成**: 日勤（早/遅含む）と夜勤の自動割り当て。
*   **休日数の自動算出 (Holiday Quota)**:
    *   月間の「土曜」「日曜」の数と、ユーザーが入力した「祝日数（または日付）」の合計を、その月の全スタッフの休日数として固定します。
    *   全員が平等な休日数を取得するようにスケジューリングされます。
*   **土日連休の保証 (Weekend Consecutive Holidays)**:
    *   「土・日・月のいずれかを含む2連休以上」を、全スタッフに対して**月2回以上**確保するように試みます。
*   **均衡ある人員配置**:
    *   クラスA（夜勤可能者）の温存と、余剰人員の動的配分により、月初の使いすぎを防ぎます。
    *   夜勤に伴う「明け」休みも考慮した上で、正確な休日規定数を遵守します。
*   **視覚的な不足アラート**: 人員不足の日を青色でハイライト表示。
*   **ランダム生成機能**: 作成ボタンを押すたびに、微妙に異なるシフト案を提案します。
*   **マトリクスCSV出力**: エクセル等で加工しやすい形式で出力。
*   **iCalendar (.ics) 出力**: Googleカレンダー等に取り込み可能。

## 使い方

1.  `index.html` をブラウザで開きます。
2.  **設定**:
    *   対象月を選択します。
    *   各勤務帯の必要人数を入力します。
    *   **祝日設定**: 今月の祝日の「日数（例: 2）」または「日付（例: 2026-02-11）」を入力します。
        *   ※休日総数は「土日の回数 + ここに入力した数」になります。
3.  **職員・希望**:
    *   職員リスト、希望休などを入力します。
4.  「シフト自動作成」をクリックします。
5.  **検証レポート**ボタンで、全スタッフの休日数や連休回数が目標を満たしているか確認できます。
